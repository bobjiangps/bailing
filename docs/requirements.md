# 需求规格说明

> 版本：v1.0（2026-10-13）　状态：已确认，待开发

## 1. 背景与目标

- 为自己和家人搭建一个私人的「相册 + 音乐」站点。
- 风格：小清新、现代、简约但精巧；整体给人**慵懒、放松、艺术小资**的感受。
- 运行环境：阿里云 ECS 突发性能型 **1 核 1G**，**Ubuntu 20.04**；要求资源占用低、速度快。
- 平台：**Web + PWA + Windows / macOS 桌面端**。不做 Android / iOS 原生 App。
- 学习目标：通过本项目学习 Go 与 Svelte。

## 2. 用户与权限

| 角色 | 能看到什么 |
|---|---|
| 访客（未登录） | 只有主页：背景、动效、两个入口。点击入口会跳转到登录页。**不展示**任何统计、照片、歌曲信息 |
| 家庭成员（已登录） | 全部相册与音乐；自己的「最近 / 最常」统计；个人偏好（主题、语言、EXIF 开关等） |
| 管理员（家庭成员之一） | 以上全部，另外可以手动重新扫描媒体库、管理落雪脚本（第三阶段） |

- 每人一个账号，账号用命令行创建，**不开放注册**。
- 所有媒体文件（原图、缩略图、音频、封面）都需要登录后才能访问。
- 登录失败会被限速，防止暴力破解；必须通过 HTTPS 访问。
- 桌面端单机模式可以选择免登录（仅允许监听本机地址时生效）。

## 3. 主页

- 汇总页，包含「相册」「音乐」两个大入口。
- 艺术感的背景：缓慢流动的柔和色块渐变、纸张颗粒质感、轻微的视差与漂浮效果。
- 时间问候语和一句轮换的短句（例如「午后，适合发呆」）。
- 已登录时，在页面底部显示一条**小巧的便签区**，不能影响整体美感：
  - 标签：最近播放 / 最常播放 / 最近看过 / 最常看过；
  - 每项最多显示 5 条，默认折叠为一行，点开后展开。
- 右上角：配色、深浅色、语言切换，以及登录 / 头像。
- 全局迷你播放器：音乐播放时常驻在页面底部，在各页面之间切换时不中断播放。

## 4. 相册

### 4.1 媒体组织

- 配置一个或多个**图片根目录**（多个时合并成一个书架，2026-10-21），根目录下的**每个子文件夹就是一个相册**；直接放在根目录里的照片也组成一个相册，以根目录名命名（2026-10-21）（只认一层子文件夹，更深的子文件夹会被忽略或在后续版本支持）。
- 每个相册有几张到几百张照片，极少超过一千张。
- 支持的格式：**JPEG、PNG、WebP、HEIC/HEIF**（苹果手机）、GIF（只取静态首帧）。
- 照片的来源是网络下载和手机拍摄。

### 4.2 about.txt

每个相册目录下可以放一个可选的 `about.txt`（UTF-8 编码，可以带 BOM）：

```text
title: 京都 · 春
cover: IMG_0012.HEIC
date: 2024-04
---
这里写相册描述，
可以写多行。
```

| 字段 | 含义 | 缺省时 |
|---|---|---|
| `title` | 相册名 | 用目录名 |
| `cover` | 封面文件名（相对于相册目录） | 用排序后的第一张照片 |
| `date` | 显示用的日期文本 | 不显示 |
| `---` 之后的内容 | 描述 | 不显示 |

- 字段名不区分大小写，也支持中文键名：`标题`、`封面`、`日期`。
- **兼容简单写法**：如果文件里没有任何可识别的字段，就把第一行当作相册名，其余内容当作描述。
- 没有 `about.txt` 时，只显示目录名作为相册名。

### 4.3 相册列表（书架）

- 每个相册显示为一本拟物相簿：有书脊、布纹或皮纹封面、贴在封面上的照片、相册名。
- 鼠标悬停或手指按住时，相簿轻微抬起、倾斜，并出现柔和的阴影。
- 根据屏幕宽度自适应排列。

### 4.4 打开相簿

- 点击相簿后：其他相簿变淡、虚化 → 被点的相簿推近到屏幕中央 → 封面翻开。
- **桌面端双页对开翻页**；**手机竖屏单页**，**手机横屏双页**。
- 翻页方式：左右滑动、拖动书角、点击左右箭头、键盘 ← →。
- 显示页码 / 进度；关闭时按相反的动画合上相簿，退回书架。
- 只加载当前页附近的几页，保证几百张照片也流畅。

### 4.5 查看照片

- 点击相簿里的照片：照片从它在页面上的位置平滑放大到全屏，背景虚化变暗。
- 缩放：鼠标滚轮、双指捏合、双击切换 1× / 适应屏幕。
- 拖动：鼠标拖动或单指拖动。
- **任意角度旋转**：
  - 桌面端：拖动图片外圈的旋转手柄，或按住 Shift 再拖动；另有 ↺90° / ↻90° 按钮和快捷键 R。
  - 手机端：双指旋转。
  - 角度范围是 **-180° ~ +180°**，正数表示顺时针、负数表示逆时针；界面上显示一个角度小标签（如「↻ 23°」）。
  - 靠近 0°、±90°、180° 时在 ±4° 范围内**自动吸附**，方便摆正。
  - 双击角度标签可以复位。
- **EXIF 面板**：默认隐藏，用一个开关显示；用户的选择会被记住。显示相机、镜头、焦距、光圈、快门、ISO、拍摄时间、分辨率。GPS 位置默认不显示，可在设置中单独开启。
- 不提供下载按钮。
- 关闭时照片缩回到相簿里原来的位置。
- 打开照片计入「查看」统计。

## 5. 音乐

### 5.1 本地音乐

- 配置一个或多个**音乐根目录**（多个时合并成一个曲库，2026-10-21），递归扫描。
- 本地歌曲和落雪歌曲可以下载到本机（2026-10-21；落雪歌曲经服务器转发，消耗流量）。
- 格式：mp3、m4a/aac、flac、ogg/opus、wav（以浏览器原生能播放的为准）；APE、WMA 等会被跳过，并在扫描日志中提示。
- 像车机一样读取文件里的元数据：标题、歌手、专辑、专辑歌手、音轨号、年份、流派、**内嵌封面**。
  - 没有封面时，依次找同目录下的 `cover.jpg`、`folder.jpg` 或同名图片，都没有则用默认的唱片图案。
  - 没有标题时用文件名。
- 歌词：
  - 优先读取同名 `.lrc` 文件（支持 UTF-8 和 GBK 编码），其次读取文件里的内嵌歌词；
  - 本地都没有时，从公共歌词库 **LRCLIB**（lrclib.net，免费、无需密钥）按歌名、歌手、专辑、时长下载，缓存后加载；可选同时保存为同名 `.lrc`；
  - 下载不到、也没有本地歌词时，显示默认提示文字（纯音乐另有提示）；没找到的歌一段时间内不重复查询；
  - 匹配错误时可以一键「重新查找」；
  - 同一时间戳出现两行时，第二行作为**翻译歌词**显示。
- 浏览方式：全部歌曲 / 文件夹 / 歌手 / 专辑；支持搜索和排序。

### 5.2 播放器（参考豆瓣 FM、网易云网页版、MusicPlayer2）

| 功能 | 阶段 |
|---|---|
| 转动的唱片封面，暂停时停在当前角度，唱针抬起 / 落下 | 1 |
| 播放 / 暂停、上一首 / 下一首、进度拖动、音量、静音 | 1 |
| 播放模式：顺序、列表循环、单曲循环、随机 | 1 |
| 播放队列：查看、插入「下一首播放」、移除、清空 | 1 |
| 歌词滚动高亮，点击某句跳到对应位置；支持翻译歌词 | 1 |
| 背景取封面主色，切歌时颜色缓慢过渡 | 1 |
| 快捷键（空格、← →、↑ ↓、M），手机锁屏和耳机按键控制 | 1 |
| 记住队列、当前歌曲和进度，下次打开继续 | 1 |
| 全局迷你播放器 | 1 |
| 收藏（我喜欢）、自定义歌单 | 2 |
| 定时停止播放 | 2 |
| 频谱可视化、均衡器（只对本地音乐有效） | 2 |
| 播放速度调节 | 2 |

### 5.3 在线源

| 来源 | 说明 | 阶段 |
|---|---|---|
| 在线直链 | mp3、flac、m4a 等地址；m3u、pls 播放列表文件 | 2 |
| HLS（m3u8） | 用 hls.js 播放 | 2 |
| 网络电台 | Radio-Browser 开放目录，可按国家、语言、标签搜索，可收藏 | 2 |
| 落雪音乐自定义源 | 自己放入落雪可用的源脚本后即可搜索并播放（见架构文档第 7 节） | 3 |

- **不接入**网易云、QQ 音乐等官方平台。
- 落雪源用于自用和调试，**风险由使用者自行承担**（落雪源的底层来源仍是各大音乐平台）。
- 播放在线源时优先由浏览器直接连接音源，必要时才通过服务器转发（见架构文档）。

### 5.4 统计

- 一首歌播放 ≥ 30 秒或 ≥ 50% 时长，记一次播放。
- 打开相册记一次相册查看；在查看器里打开照片 ≥ 1 秒记一次照片查看。
- 主页便签区显示最近播放、最常播放、最近看过、最常看过，按用户分别统计。

## 6. 通用需求

- **主题**：浅色 / 深色 / 跟随系统；**5 套配色**（详见设计文档）。
- **语言**：中文 / English，默认跟随浏览器语言。
- **响应式**：手机、平板、桌面；支持触控手势。
- **无障碍**：键盘可操作；尊重系统的「减弱动态效果」设置，开启时用淡入淡出代替大幅动画；保证足够的对比度。
- **PWA**：可以安装到桌面或主屏幕；页面外壳离线可用（媒体文件不离线）。
- **性能**：
  - 服务器常驻内存目标 < 80MB（不含 nginx）；
  - 主页首屏 JS（gzip 后）目标 < 80KB；
  - 列表中的缩略图每张约 30KB。

## 7. 非目标

- 不做照片上传和编辑（用 rsync 或 Syncthing 同步文件即可）。
- 不做 Android / iOS 原生 App。
- 不做多租户和开放注册。
- 不做服务端音频转码。
