# 视觉与交互设计规范

> 关键词：**慵懒 · 留白 · 纸感 · 柔光 · 慢**

## 1. 设计原则

1. **留白优先**：内容占比低，大面积柔和背景，让眼睛休息。
2. **慢而顺滑**：动画偏慢（400–800ms），使用柔和缓动或低刚度弹簧，没有突兀的跳变。
3. **拟物点到为止**：相簿、唱片、便签有真实质感（纸纹、布纹、阴影），但不堆砌细节。
4. **颜色来自内容**：音乐页背景取封面主色，相册封面决定相簿的色调。
5. **克制的信息**：统计、EXIF 等信息默认收起，需要时再展开。
6. **可降级**：开启系统的「减弱动态效果」时，大幅动画改为淡入淡出；低端设备自动关闭模糊和颗粒效果。

## 2. 字体

| 用途 | 字体 | 说明 |
|---|---|---|
| 标题、相册名、歌词 | **霞鹜文楷 LXGW WenKai**（SIL OFL 1.1 许可） | 使用按 Unicode 范围分片的网页字体，只下载页面上用到的字 |
| 正文、界面文字 | 系统字体栈：`-apple-system, "PingFang SC", "Microsoft YaHei", "Segoe UI", sans-serif` | 不额外下载 |
| 数字（时间、角度） | `ui-monospace` 或等宽数字 `font-variant-numeric: tabular-nums` | 数字跳动时宽度不变，不会抖动 |

## 3. 配色体系

### 3.1 实现方式

- 配色由 **「配色方案（palette）× 深浅色（mode）」** 两层组合而成，通过 `<html data-palette="monet" data-mode="dark">` 切换。
- 全部使用 CSS 变量（设计令牌，也就是统一命名的颜色、圆角等变量），组件中**禁止写死颜色**。
- 用 OKLCH 颜色空间做插值，渐变和颜色过渡更自然。

## 4. 动效规范

### 4.1 缓动与时长

| 令牌 | 值 | 用途 |
|---|---|---|
| `--ease-soft` | `cubic-bezier(.22,.8,.24,1)` | 大多数进入动画 |
| `--ease-out-gentle` | `cubic-bezier(.33,1,.68,1)` | 淡出、收起 |
| `--dur-fast` | 180ms | 悬停、按下 |
| `--dur-base` | 360ms | 面板、弹层 |
| `--dur-slow` | 700ms | 推近相簿、翻开封面 |
| 弹簧（Motion） | stiffness 120, damping 20 | 相簿推近、照片飞出与飞回 |

### 4.2 关键动效

| 场景 | 动效描述 |
|---|---|
| 主页背景 | 3 个大的模糊色块以 40–60 秒为周期缓慢漂移；叠加一层 SVG 噪点颗粒（透明度 4–6%）；鼠标移动时有很轻的视差（≤ 12px）。**只动画 transform 属性**，节省性能 |
| 主页入口卡片 | 相册卡：几张倾斜的拍立得照片，悬停时微微散开；音乐卡：一张缓慢旋转的黑胶唱片，悬停时转速加快一点 |
| 便签区 | 折叠成一行的小标签；展开时向上滑出约 160px 高，带毛玻璃效果 |
| 书架入场 | 相簿依次（每本间隔 40ms）从下方 12px 处淡入 |
| 相簿悬停 | 抬起 6px，`rotateX(4deg) rotateY(-6deg)`，阴影变大变柔 |
| **打开相簿** | ① 其他相簿变淡、模糊（300ms）→ ② 被点的相簿用 FLIP 动画移动并放大到屏幕中央（弹簧，约 600ms）→ ③ 封面绕书脊翻开（约 700ms）→ ④ 显示翻页控件。关闭时按相反顺序 |
| 翻页 | StPageFlip 仿真翻页，带页面卷曲和阴影；手机竖屏改为单页 |
| **查看照片** | 共享元素过渡：照片从页面上的位置放大到屏幕中央（约 450ms 弹簧），背景虚化变暗。关闭时飞回原位 |
| 旋转 | 拖动时实时旋转；松手后有轻微惯性；吸附到 0°、±90°、180° 时有轻微的「咔哒」回弹 |
| 唱片 | 播放时匀速旋转（约 20 秒一圈）；暂停时停在当前角度，不跳回原位；唱针抬起 / 落下约 400ms |
| 切歌 | 封面交叉淡入淡出，背景主色过渡约 1.2 秒 |
| 歌词 | 当前句放大到 1.08 倍并加深颜色，平滑滚动到中间偏上的位置 |
| 页面切换 | 优先使用浏览器的 View Transitions API（页面过渡接口）；不支持的浏览器用淡入淡出代替 |

### 4.3 性能约束

- 动画只改变 `transform` 和 `opacity` 两种属性，这两种由显卡合成，不会触发页面重新排版。
- `backdrop-filter`（毛玻璃效果）全页最多同时出现 2 处；检测到低端设备时用纯色半透明代替。
- 用户开启「减弱动态效果」（`prefers-reduced-motion`）时：背景静止，推近和飞出改为 200ms 淡入淡出，唱片不转。

### 5.2 相册书架 → 相簿 → 查看器

```
书架（网格）              打开后（桌面端）                   查看器
┌──┐┌──┐┌──┐            ┌─────────┬─────────┐       ┌──────────────────┐
│▤ ││▤ ││▤ │   ──►    ‹ │  照片   │  照片   │ ›  ──►│      ⟳ ↻23°      │

└──┘└──┘
```

- **书架封面**：照片框固定为正方形（`min-height:0` + 绝对定位的图片，`object-fit: cover`），不论原图多细长都不会把相簿名挤出封面。
- **页面内居中**：PageFlip 会把每页强制设为 `display:block`，所以居中的 flex 容器放在页内的 `.pg-in` 上；一页只有一两张照片时上下留白相等（底部预留页码位置）。
- **翻到最后**：最后一页照片可见时，底部页码旁出现「回到第一页」「返回书架」两个胶囊按钮，右侧箭头变成「回到第一页」；`Home` 键回第一页。
- **层级**：打开的相簿（z 50）和查看器（z 60）盖住顶栏（30）和播放条（35）。`<main>` 不能设 z-index，否则会形成层叠上下文，里面的浮层永远在顶栏之下。
- **快捷键提示**：底部一行小字「← → 翻页 · Home 回到第一页 · Esc 返回书架」（窄屏隐藏）；各按钮的 title 带上对应按键。

### 5.3 音乐页（桌面端）

```
┌───────────────────────────────────────────────────────┐
│ 全部 · 文件夹 · 歌手 · 专辑 · 我的 · 电台 · 在线  🔍  │
├───────────────────────┬───────────────────────────────┤
│        ╲ 唱针         │   歌词（滚动高亮）             │
│     ◎ 旋转的唱片      │   当前句                       │
│   ▁▃▅▇▅▃▁ 频谱条      │   下一句                       │
│      歌名 / 歌手      │                               │
├───────────────────────┴───────────────────────────────┤
│ ⇄ ⏮ ⏯ ⏭  0:42 ────●──── 3:58  ☆ ＋  🔊  ⚙ ☰          │
└───────────────────────────────────────────────────────┘
背景：用封面主色生成的柔和渐变 + 高度模糊的封面
```

- **宽屏（≥ 1100px）**：左边唱片、右边歌词，两栏各占一半，歌词栏吸顶；曲库 / 我的 / 电台 / 在线收进从左侧滑出的抽屉（宽 `min(600px, 48vw)`），左上角「曲库」按钮或 `L` 键开合，`Esc` 关闭，开合状态存在 `localStorage`（`bl.libOpen`）。抽屉关闭时设 `inert`，键盘焦点不会进去。
  - **自动模式**（默认开，`bl.libAuto`）：开始播放 0.7 秒后收起、暂停 0.9 秒后展开（延迟避免切歌间隙闪动）；只在播放 / 暂停切换时动作，其余时间完全由用户控制。
  - 抽屉顶部一栏：说明文字（曲库盖在歌词上、何时自动收起、快捷键）、「播放时自动收起」复选框、「收起曲库 Esc」按钮；关闭后右上角「曲库 L」按钮。按键用 `<kbd>` 样式显示。
- **窄屏 / 手机端**：保持原布局，全屏播放页，左右滑动在「唱片 / 歌词」之间切换；播放列表从底部抽屉弹出。
- **下载按钮**：曲库行、落雪搜索结果行、正在播放区域（流量标记旁）；下载中显示转圈，失败时按钮上方提示 6 秒，音质低于所选时提示 8 秒。
  - **落雪下载确认框**（2026-10-26）：原生 `<dialog>` + `showModal()`（顶层显示，不受抽屉 transform / z-index 影响，焦点留在框内，`Esc` 关闭）；宽 `min(400px, 100vw - 32px)`，背景半透明遮罩。内容：标题「下载到本机」→ 歌名（大）/ 歌手 · 专辑 + 平台小标签 → 「音质」下拉（`128k · 3.18MB` 形式，来自搜索结果 `_types`，按音质从低到高；默认取设置音质，没有该档就取不高于它的最好一档）→ 「文件大小 约 7.95MB」→ 流量与降级说明 → 「以后不再询问」→ 右下「取消 / 下载」（下载为主按钮并自动聚焦）。只有落雪行渲染 `<dialog>`（本地列表可能有几千行）。偏好 `dlAsk`（默认开）。打开确认框时播放条和曲库的快捷键暂停响应。
- 「我的 / 电台 / 在线」三个标签是扩展来源，样式与本地曲库标签略作区分（`.ext`）。
- **曲库列表头**（2026-10-26）：第一行「N 首歌 · ◎ 定位 · ＋ 全部加入歌单 · ▶ 播放全部」；第二行「排序 [下拉框] [正序 | 倒序]」分段按钮，与设置页的分段按钮同样式。排序存 `localStorage`（`bl.musicSort`）。
- **跟随正在播放**：切歌后若列表在视野内（宽屏：抽屉打开；窄屏：列表顶部在视口 60% 以上）且未在搜索，将当前行 `scrollIntoView({block:'center', behavior:'smooth'})`；当前行已完整可见时不滚动（上方扣除固定的标签栏，窄屏下方扣除播放条）。例外：宽屏自动模式下抽屉是自动打开的、而播放器处于「播放或加载中」（即将自动收起）时不滚动，避免一闪而过的滑动。抽屉打开 / 列表重新加载时，在下一帧用 `instant` 定位，抽屉滑入时已经停在当前歌曲。
- **自动收起的判断**：看「播放中或加载中」（`playing || loading`，用 `$derived` 保证只在真正翻转时触发），切歌和加载下一首不再被当作暂停。用户手动打开的抽屉（`L` / 按钮）在切歌时保持打开并平滑滚动。
- **固定标签栏**：`.lib-head`（标签 + 搜索框）`position: sticky`；抽屉内 `top: 0`（抽屉自身是滚动容器），窄屏 `top: var(--topbar-h)`；背景 90% 不透明表面色 + 模糊，左右用负边距铺满曲库宽度。再点当前标签回到列表顶部（不另加「回到顶部」按钮）。
- **手机端宽度约束**：单列网格用 `minmax(0, 1fr)`，所有列 `min-width: 0`，并 `overflow-x: clip` 兜底（不产生滚动容器，不影响 sticky）。曲库和电台的搜索框在 ≤ 640px 时独占一行；电台的「全部 / 收藏」与地区下拉框同一行，下拉框可收缩。
- **频谱条**：唱片下方，宽度 = 唱片宽度 + 40px（最大 380px），高 56px，48 根圆角细条（40 Hz–16 kHz 对数分段），颜色取 `--accent`，透明度随电平在 35%–100% 之间变化；「快升慢落」。仅在设置中开启频谱且音效链已接入时显示，暂停时逐渐落回 2px 基线。
- **播放栏新增按钮**：☆ 收藏当前歌曲（已收藏为实心）、＋ 加入歌单（弹出歌单列表，可就地新建）、⚙ 打开「音效与定时」面板。

### 5.4 我的（收藏与歌单）

- 顶部三段切换：**收藏的歌 · 收藏的电台 · 歌单**。
- 列表行右侧统一放 ☆ 按钮；空状态用一句柔和提示（如「点歌曲右边的 ☆ 就能收藏」），不放大插画。
- 歌单详情：可重命名、删除（二次确认，说明「歌曲本身不会被删除」）、上移、移除单曲；「把播放列表存为歌单」放在列表底部。
- 底部一行次要文字说明：收藏和歌单保存在服务器上，换设备登录后仍在。

### 5.5 音效与定时面板

- 毛玻璃浮层，从播放栏上方弹出，标题「音效与定时」。
- **播放速度**：0.75 / 1 / 1.25 / 1.5 / 2 的分段按钮；电台直播固定为 1 并给出说明。
- **定时停止**：关闭 / 15 / 30 / 45 / 60 / 90 分钟 / 放完这首；生效时在标题旁显示剩余时间（等宽数字）；电台直播时「放完这首」不可用。
- **均衡器**：10 段（31 Hz–16 kHz）竖向滑杆 + 预设标签（原声、低音、人声、流行、摇滚、爵士、古典、高音）；总开关关闭时滑杆变淡。

### 5.6 新版本提示（PWA）

- 安装为应用后检测到新版本时，在顶栏下方 10px 居中弹出胶囊形毛玻璃提示：「有新版本」+ 主按钮「刷新」。
- 不自动刷新、不遮挡内容，用户点按后才切换到新版本。

## 6. 图标与插画

- 图标：**Lucide**（ISC 许可），线条风格，描边宽度 1.5。
- 相簿布纹、纸纹：用 CSS 或 SVG 程序生成，不使用大图片。
- 默认唱片封面：用 SVG 生成的渐变唱片。
